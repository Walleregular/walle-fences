Walle Fences 1.0.0 · Windows x64

ЗАПУСК
1. Распакуйте весь архив в постоянную папку.
2. Запустите WalleFences.exe. .NET и шрифт входят в пакет.
3. Выберите язык и простые или продвинутые настройки при первом запуске.
4. Создайте группу в «Рабочий стол», добавьте файлы, программы или портал.

Закрытие настроек оставляет группы работающими.
Выход: ПКМ по значку Walle Fences в трее → «Выход».
Настройки открываются через Ctrl + Alt + M.

РАБОЧИЙ СТОЛ
В основной вкладке доступны «Группы», «Виджеты» и «Наборы».
Миниатюры показывают обои и содержимое групп на подключённых экранах.
Выберите группу в списке: инспектор справа задаёт монитор, край,
длину, раскрытие, размер, прозрачность и содержимое вкладок.
Значок слева от названия открывает палитру из 24 вариантов.
Цвета, форма и поведение сохраняются отдельно для каждой группы.

Полоски располагаются сверху, снизу, слева или справа; толщина 2–12 DIP.
Длина: своя, весь край или равные блоки, например пять частей ширины.
Соседние полоски расталкиваются при перемещении и изменении длины.
Раскрытие: приближение, остановка курсора, наведение, щелчок,
двойной щелчок, горячая клавиша или постоянное раскрытие.
Вкладки можно скрыть, показывать всегда либо только при нескольких вкладках.
ПКМ на группе, вкладке или содержимом открывает соответствующие действия.
Вкладки переносятся с Shift; группы объединяются с Ctrl при перетаскивании.

НАГЛЯДНОЕ ОБУЧЕНИЕ
«Рабочий стол» → «Управление» → «Показать обучение».
Подсказки подсвечивают настоящие кнопки; обучение можно прервать и продолжить.
Язык, режим настроек и повторное обучение также доступны в «Настройки».

НАБОРЫ
Переключайте их вкладками сверху, в трее или Ctrl + Alt + ← / →.
Для создания нажмите «Новый набор» либо откройте «Рабочий стол» → «Наборы».
Доступны пустой набор, копия текущего, файловые вкладки и виджеты.
Группы, вкладки, виджеты и положения в каждом наборе независимы.
Наборы Walle не связаны с виртуальными рабочими столами Windows.

ВИДЖЕТЫ
Нажмите «Добавить виджет» на рабочем столе, в представлении «Виджеты»
либо через меню группы: «Добавить» → «Добавить виджет…».
В каталоге есть поиск, категории, предпросмотр и параметры.
Каждый новый виджет появляется отдельной панелью текущего набора.
Отмена не создаёт панель. Размер и положение настраиваются отдельно.

13 видов: часы и дата, заметка, фокус-таймер, CPU и память,
температура CPU, топ процессов, оперативная память, видеокарта,
свободное место, сеть, батарея, загрузка CPU и время работы ПК.
Для GPU и сети можно выбрать адаптер; для процессов — сортировку и число строк.

ТЕМПЕРАТУРЫ БЕЗ ОТДЕЛЬНЫХ ЗАГРУЗОК
LibreHardwareMonitorLib и установщик PawnIO входят в комплект.
В виджете температуры или настройках нажмите «Включить аппаратные датчики»
и подтвердите запрос Windows. Процесс датчиков получит повышенные права;
при отсутствии драйвера он установит включённый в комплект PawnIO.
Основной интерфейс сохраняет обычные права и перетаскивание файлов.
Интернет не нужен. Показания обновляются без перезапуска Walle Fences.

Доступ действует в текущем сеансе. После нового запуска при необходимости
нажмите ту же кнопку; установленный драйвер повторно устанавливать не нужно.
При необходимости перезагрузки Windows программа сообщит об этом.
Обычный запуск не устанавливает драйвер и не вызывает повышение прав.
Неподдерживаемый датчик показывает прочерк и причину.

Переносите всю папку программы, включая DLL и Assets.
Установщик: Assets\Hardware\PawnIO\PawnIO_setup.exe.
Лицензии компонентов: Assets\Licenses. Manrope: Assets\Fonts\OFL.txt.

ПРОГРАММЫ И АВТОСОРТИРОВКА
В «Добавить программы» и поиске есть «Избранное» и «Недавние».
Звезда добавляет программу в избранное; то же действие доступно по ПКМ.
Недавние учитывают запуски программ через Walle с их параметрами.
Очистка недавних сохраняет избранное.

«Автоматизация» → «Предпросмотр» показывает правила, назначения и причины
пропуска до добавления ссылок. «Применить» обрабатывает подходящие строки,
оставшиеся после поиска и фильтров. Исходные файлы остаются на месте.
Несохранённое правило можно просмотреть без применения.

ИГРОВОЙ РЕЖИМ
«Настройки» → «Игровой режим» предотвращает автоматическое раскрытие
поверх полноэкранного приложения на занятом мониторе.
Другие экраны, ручное открытие и Ctrl + Alt + Space остаются доступны.

СОЧЕТАНИЯ ПО УМОЛЧАНИЮ
Ctrl + Alt + Space — быстрый доступ поверх окон; Esc — закрыть.
Ctrl + Alt + H — скрыть / показать группы.
Ctrl + Alt + K — поиск файлов, программ и команд.
Ctrl + Alt + M — настройки.
Ctrl + Alt + ← / → — предыдущий / следующий набор.
Ctrl + Tab / Ctrl + Shift + Tab — следующая / предыдущая вкладка группы.
Глобальные сочетания меняются в настройках.

ДАННЫЕ И ОБНОВЛЕНИЕ
Профиль: %LOCALAPPDATA%\WalleFences.
workspace.json — настройки и ссылки, .bak — предыдущая версия.
programs.json — избранные и недавние программы; snapshots — снимки раскладки.
Снимки сохраняют раскладку, а не сами пользовательские файлы.
Удаление ссылки, вкладки или группы не удаляет исходные файлы.
Действия меню Windows относятся к настоящему файлу.

При обновлении завершите старую программу через трей и запустите новый EXE.
Профиль сохранится. Если изменилась папка программы, заново включите
автозагрузку в новой версии, чтобы обновить путь запуска с Windows.
